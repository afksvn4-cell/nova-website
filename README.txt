NØVA — Personal Website

Cách xem:
1. Giải nén nova_personal_website.zip.
2. Mở thư mục nova_personal_website.
3. Nhấp đúp index.html để mở website trong trình duyệt.

Chỉnh sửa:
- index.html: nội dung và các mục trên trang.
- style.css: màu sắc, font chữ, bố cục và hiệu ứng.
- script.js: menu, hiệu ứng xuất hiện, thanh tiến trình cuộn.

Đưa lên Internet:
Có thể xuất bản miễn phí bằng GitHub Pages. Tải cả 3 tệp lên repository, sau đó vào Settings > Pages và chọn Deploy from a branch > main > /(root).

Lưu ý:
- Website hiện là bản tĩnh, không có backend hay biểu mẫu gửi dữ liệu.
- Tên NØVA là tên concept do dự án tự đặt; bạn có thể đổi trong index.html.
- Website dùng Google Fonts khi có Internet; nếu ngoại tuyến sẽ dùng font dự phòng.
